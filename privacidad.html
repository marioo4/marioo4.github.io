Política de privacidad de PaquitoAI

Última actualización: 12 de octubre de 2026

Quién la usa

PaquitoAI es una aplicación de uso personal. Solo la usa su propietario con su propia cuenta de Google. No se ofrece a otras personas.

Qué datos de Google lee

Con el permiso expreso del propietario, y siempre en modo de solo lectura:

  • Gmail (gmail.readonly): buscar y leer correos.
  • Google Calendar (calendar.readonly): ver eventos.
  • Google Drive (drive.readonly): buscar y leer archivos.
  • Dirección de correo de la cuenta (openid, email): saber qué cuenta está conectada.

La aplicación no envía, borra ni modifica correos, eventos ni archivos.

Para qué se usan

Solo para responder a las peticiones del propietario a su asistente personal (por ejemplo, «¿qué tengo mañana en el calendario?»). No se usan para publicidad, no se venden y no se comparten con terceros.

Dónde se guardan

  • El token de acceso de Google se guarda en un servidor privado del propietario, en un fichero que solo puede leer su usuario, y nunca sale de él salvo en las copias de seguridad, que van cifradas.
  • El contenido de correos, eventos y archivos no se almacena de forma permanente: se lee cuando hace falta para responder.
  • Para generar la respuesta, el texto necesario se envía al modelo de lenguaje que usa el asistente, bajo la cuenta del propio propietario.

Uso limitado

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

  • Desde la app: Ajustes → Conexiones → Google → Desconectar. Revoca el permiso y borra el token del servidor.
  • Desde Google: myaccount.google.com/permissions → PaquitoAI → Quitar acceso.
